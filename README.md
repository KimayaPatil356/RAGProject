# CloudSync Pro Customer Support Agent

A knowledge-base driven customer support agent built with Python and LangGraph.

The system retrieves relevant information from a product knowledge base and provides support responses through an interactive CLI. It also identifies issues that require human escalation.

## Features

- Knowledge-base driven support
- Custom Markdown knowledge base
- LangGraph-based workflow
- Keyword-based document retrieval
- Automatic support escalation
- Source attribution
- Interactive CLI interface
- Custom knowledge-base directory support

## Tech Stack

- Python
- LangGraph
- LangChain
- Markdown
- Rule-based Information Retrieval
