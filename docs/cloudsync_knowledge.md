# CloudSync Pro Knowledge Base

## Product Features

CloudSync Pro provides real-time synchronization across up to 5 devices.

The Pro plan includes 1TB of storage.

CloudSync Pro supports offline mode.

Version history is available for 30 days.

## Pricing

Basic: $9/month with 100GB storage and 2 devices.

Pro: $19/month with 1TB storage and 5 devices.

Business: $49/month with 5TB storage and unlimited devices.

## Cancellation and Refunds

Customers can cancel their subscription from:

Account > Subscription > Cancel

Refunds are available within 14 days of the charge.

## Password Reset

To reset a password:

1. Go to the login page.
2. Click "Forgot Password".
3. Enter the registered email address.
4. Follow the reset link.

The password reset link expires after 1 hour.

## Sync Troubleshooting

If synchronization is not working:

1. Check the internet connection.
2. Make sure the application is updated.
3. Sign out and sign in again.
4. Contact support if the problem continues.

## Supported Platforms

CloudSync Pro supports:

- Windows 10+
- macOS 12+
- iOS 15+
- Android 10+
- Linux (Beta)

## Data Security

CloudSync Pro uses AES-256 encryption for data at rest and in transit.

The service is SOC 2 Type II certified.

CloudSync Pro uses a zero-knowledge architecture.

## File Size Limits

Individual files can be up to 10GB on Pro and Business plans.

Basic plan users can upload individual files up to 2GB.

There is no limit on the total number of files.
